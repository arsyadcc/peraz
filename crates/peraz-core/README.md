# peraz-core

The domain model of [Peraz](https://github.com/arsyadcc/peraz): media info, jobs, recipes, plans,
and reports. No I/O.

This crate is an implementation detail of the `peraz` command-line tool; its API is not stable yet.
To compress files, install the tool instead: see the [Peraz README](https://github.com/arsyadcc/peraz#installation).
